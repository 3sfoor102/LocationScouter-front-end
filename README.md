# LocationScouter
An interactive geolocation database and full-stack application to seamlessly discover, map, and track prime photography and videography spots!

![](Pasted%20image%2020260812160112.png)

---
## Getting Started

### Use the Application
[Deployed Application - Front End](https://locationscouter.netlify.app)

---
## How It Works
* **Discover Locations:** Browse an interactive database of mapped photography points and scenic spots.
* **Track Conditions:** Access weather analytics and track lighting conditions to plan for the perfect shot.
* **Record Coordinates:** Pinpoint specific scout coordinates and save new locations directly to the map.
* **Manage Data:** View, edit, or remove your saved photography locations from your personalized tracking board.

---

## Installation
No complex setup required for local development! Simply clone the repository and start the server:

```bash
git clone https://github.com/3sfoor102/LocationScouter-back-end.git](https://github.com/3sfoor102/LocationScouter-front-end.git)
cd LocationScouter-front-end 

npm install 

npm start
```
Open `https://locationscouter-back-end.onrender.com` in your browser to view the back-end application.

## Technologies Used
- **React** (Frontend User Interface & Mapping Components)
- **Node.js & Express** (Backend Server & API Routing)
- **MongoDB & Mongoose** (Database & Data Modeling)
- **Third-Party APIs** (Weather Analytics & Geolocation Tools)
